# Автоматизация отчётов

Скрипт собирает данные из нескольких источников и присылает сводку в Telegram. Запускается вручную или по расписанию (cron / Планировщик заданий Windows). Внешних зависимостей нет, только стандартная библиотека Python.

**Стек:** Python 3.10+, cron, REST API (ЦБ РФ, Open-Meteo, GitHub, Telegram Bot API).

## Пример сводки

```
📊 Сводка за 02.10.2026

💱 Курсы ЦБ
USD: 83.25 ₽ ▼ -0.31
EUR: 94.53 ₽ ▼ -0.36
CNY: 12.40 ₽ ▼ -0.07

🌤 Погода, Москва
+3…+12 °C, осадки 13%

🐙 GitHub
python/cpython: ★ 77 384 · issues 9 733 · push 2026-10-01
```

## Быстрый старт

Нужен Python 3.10 или новее.

```bash
cd report-bot
cp .env.example .env          # на Windows: copy .env.example .env
```

Откройте `.env` и впишите `BOT_TOKEN` и `CHAT_ID` (как их получить, описано ниже). Затем:

```bash
python -m report_bot --dry-run   # сводка в консоль, ничего не отправляется
python -m report_bot             # отправить сводку в Telegram
```

Команды нужно запускать из папки `report-bot`: Python ищет пакет `report_bot` в текущей папке.

## Создание бота и получение CHAT_ID

**Токен бота (`BOT_TOKEN`)**
1. В Telegram откройте `@BotFather` и отправьте `/newbot`.
2. Придумайте имя и username (должен оканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456:ABC...`. Это секрет: не публикуйте его и не коммитьте `.env`.

**Ваш чат (`CHAT_ID`)**

Личный чат:
1. Напишите `@userinfobot`: он ответит вашим числовым ID.
2. Откройте своего бота и нажмите **Start**. Без этого бот не сможет вам писать.

Группа или канал:
1. Добавьте бота в группу (в канале сделайте его администратором).
2. Отправьте в группу любое сообщение.
3. Откройте `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` и найдите `"chat":{"id":-100...}`. ID групп и каналов отрицательные, минус нужно сохранить.

## Настройки

Все настройки задаются в файле `.env`. Заданные в системе переменные окружения имеют приоритет над файлом.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен бота от BotFather |
| `CHAT_ID` | — | чат, куда отправлять сводку |
| `CITY` | `Москва` | название города, только для заголовка блока погоды |
| `LAT`, `LON` | `55.75`, `37.62` | координаты для прогноза |
| `CURRENCIES` | `USD,EUR,CNY` | коды валют по классификатору ЦБ, через запятую |
| `GITHUB_REPOS` | `python/cpython` | репозитории `владелец/имя`, через запятую |
| `HTTP_TIMEOUT` | `10` | таймаут запросов, секунды |

Пример для другого города и набора репозиториев:

```
CITY=Казань
LAT=55.79
LON=49.12
CURRENCIES=USD,EUR
GITHUB_REPOS=python/cpython,pallets/flask
```

## Запуск

| Команда | Что делает |
|---|---|
| `python -m report_bot` | собирает сводку и отправляет в Telegram |
| `python -m report_bot --dry-run` | печатает сводку в консоль, не отправляет |
| `python -m report_bot --every 30` | повторяет отправку каждые 30 секунд до Ctrl+C (для теста) |
| `python -m report_bot --dry-run --every 30` | то же, но только вывод в консоль |

Коды возврата: `0` — успех, `2` — не заданы `BOT_TOKEN` или `CHAT_ID`.

## Запуск по расписанию

### Linux / macOS (cron)

Cron каждую минуту смотрит в таблицу заданий и запускает те, чьё время подошло.

```bash
crontab -e
```

Добавьте строку (она же лежит в `crontab.example`):

```
0 9 * * 1-5 cd /opt/report-bot && /usr/bin/python3 -m report_bot >> report.log 2>&1
```

Формат: `минута час день_месяца месяц день_недели команда`.

| Запись | Когда запускается |
|---|---|
| `0 9 * * 1-5` | будни в 09:00 |
| `*/30 * * * *` | каждые 30 минут |
| `0 8 1 * *` | 1-го числа каждого месяца в 08:00 |

Важно:
- `cd ... &&` нужен, чтобы скрипт нашёл `.env`.
- Путь к python укажите полный (`which python3`): у cron урезанное окружение.
- Cron работает по времени сервера, проверьте командой `date`.
- Минимальный шаг — одна минута. Для проверки раз в 30 секунд используйте `--every`.
- Вывод и ошибки попадают в `report.log`. Проверить список заданий: `crontab -l`.

### Windows (Планировщик заданий)

1. Откройте **Планировщик заданий** → **Создать простую задачу**.
2. Выберите периодичность и время.
3. Действие: **Запустить программу**.
   - Программа: полный путь к `python.exe`.
   - Аргументы: `-m report_bot`.
   - Рабочая папка: путь к `report-bot`.

Либо запустите проект в WSL и используйте cron.

## Как устроен проект

```
report-bot/
├── report_bot/
│   ├── __main__.py   # точка входа, разбор аргументов
│   ├── config.py     # чтение .env и настроек
│   ├── sources.py    # источники данных (по функции на источник)
│   ├── report.py     # сборка итогового текста
│   └── telegram.py   # отправка в Telegram
├── tests/
├── .env.example
└── crontab.example
```

Источники данных:

| Источник | Что берёт | Ключ API |
|---|---|---|
| ЦБ РФ (cbr-xml-daily.ru) | курсы валют и изменение к прошлому дню | не нужен |
| Open-Meteo | температура и вероятность осадков на сегодня | не нужен |
| GitHub API | звёзды, открытые issue, дата последнего push | не нужен |

Если один источник не ответил (таймаут, изменился формат), сводка всё равно уходит, а в конце добавляется строка `⚠️ Не получилось: github: TimeoutError`.

Без ключа GitHub API разрешает около 60 запросов в час с одного IP. При частом тестировании через `--every` лимит можно исчерпать; тогда блок GitHub временно пропадёт.

## Как добавить свой источник

1. В `report_bot/sources.py` напишите функцию, которая принимает `Config` и возвращает текстовый блок:

```python
def quote_block(cfg: Config) -> str:
    data = fetch_json("https://example.com/api/quote", cfg.timeout)
    return f"💬 Цитата дня\n{data['text']}"
```

2. Добавьте её в словарь `SOURCES` в конце файла:

```python
SOURCES = {
    "rates": rates_block,
    "weather": weather_block,
    "github": github_block,
    "quote": quote_block,
}
```

Порядок в словаре задаёт порядок блоков в сводке. Обработку ошибок писать не нужно: её делает `build_report`.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `No module named report_bot` | команда запущена не из папки `report-bot` |
| `Задайте BOT_TOKEN и CHAT_ID` | не заполнен `.env` или он лежит не в рабочей папке |
| `HTTP Error 401` от Telegram | неверный токен |
| `HTTP Error 400` / `chat not found` | неверный `CHAT_ID`, либо вы не нажали **Start** у бота |
| `HTTP Error 403` | бот заблокирован или удалён из группы |
| в сводке `⚠️ Не получилось: …` | источник недоступен или лимит запросов; остальные блоки при этом работают |
| `KeyError` в блоке курсов | неверный код валюты в `CURRENCIES` |
| по cron не приходит | смотрите `report.log`, проверьте полный путь к python и рабочую папку |
